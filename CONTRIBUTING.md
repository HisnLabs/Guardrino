# Contributing

Thanks for helping. This repository holds the Guardrino integrations and examples (the gateway is commercial and not included).

- Open an issue first for larger changes.
- Run the LiteLLM unit tests: `cd integrations/litellm && pip install -e '.[test]' && pytest`.
- Keep examples on the placeholder host `https://guardrino.your-company.example`; never commit keys or real hostnames.
- Contributions are licensed under Apache-2.0.
- Security problems: see [SECURITY.md](SECURITY.md).
